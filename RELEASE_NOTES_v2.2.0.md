# my-alt-tab v2.2.0

**Author / maintainer / release owner: zhangqiaoran**

## Install

1. Download `my-alt-tab-2.2.0.zip`.
2. Unzip to get `my-alt-tab.app`.
3. Drag it into `/Applications`.
4. Grant Accessibility permission. Screen Recording is only needed for window previews.

## Changes

- More right-side breathing room in the switcher.
- Compact top-right ellipsis (…) action instead of the gear icon.
- More vivid fixed-cost particle dissolve when closing a window.
- Shared glass selection, fast two-window switching, and lightweight event-driven behavior remain unchanged.

Official release packages are verified as Universal 2 for Intel + Apple Silicon.
