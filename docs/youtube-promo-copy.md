## Description

Meet **my-alt-tab**, a lightweight native macOS window switcher built with Swift and AppKit.

Switch to the exact window you want — not just the app — with real window previews, fast 1↔2 Alt/Option+Tab switching, Clear Glass styling, and a particle-dissolve close animation.

### Highlights
- Lightweight native Swift / AppKit
- Fast Alt/Option+Tab switching
- Window previews
- Particle-dissolve window close
- Clear Glass style
- English / 中文 Settings
- Universal 2 — Apple Silicon + Intel
- Open source on GitHub
